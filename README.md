# Telegram AI Bot (учебный проект)

Простой телеграм-бот на Python (aiogram 3), который сейчас отвечает эхом,
а в дальнейшем будет подключён к бесплатной нейросети (с лимитами), чтобы
с ним можно было полноценно общаться. Проект задуман как учебный /
для портфолио.

## Что уже готово

- Базовая структура бота на **aiogram 3** (современный async-фреймворк,
  стандарт де-факто для телеграм-ботов на Python).
- Команды `/start`, `/help`, `/reset`.
- Обработка текстовых сообщений через отдельный сервис `bot/services/ai.py` —
  сейчас это заглушка (эхо), но именно сюда позже подключится нейросеть.
- Конфигурация через `.env` (токен бота не попадёт в git).

## Структура проекта


## Как запустить локально

### 1. Получить токен бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather).
2. Команда `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. BotFather выдаст токен вида `123456789:AA...` — сохрани его.

### 2. Установить окружение

```bash
git clone <ссылка-на-твой-репозиторий>
cd telegram-ai-bot

python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
```

Открой `.env` и вставь свой токен:

```
BOT_TOKEN=твой_токен_от_botfather
```

`AI_PROVIDER`, `AI_API_KEY`, `AI_MODEL` пока можно оставить пустыми —
они понадобятся на следующем этапе.

### 4. Запустить бота

```bash
python -m bot.main
```

Если всё ок, в консоли появится `Бот запускается...`, и бот начнёт
отвечать в Telegram.

```bash
git init
```

останется только `.env.example` — это нормальная практика.

## Следующий шаг: подключение нейросети

Требование "бесплатно, но с лимитами" отлично закрывают эти варианты:

| Сервис | Особенности |
|---|---|
| **Groq** (console.groq.com) | Бесплатный API, очень быстрый инференс, модели уровня Llama 3.1 / Mixtral. Лимиты по запросам в минуту и в день. |
| **OpenRouter** (openrouter.ai) | Агрегатор моделей, часть моделей бесплатна (помечены `:free`), OpenAI-совместимый API. |
| **Hugging Face Inference API** | Бесплатный тир с лимитами запросов, доступ ко множеству открытых моделей. |
| **Google Gemini API** | Есть бесплатный тир (лимиты по запросам в минуту/день). |

Логика уже подготовлена в `bot/services/ai.py` — там есть закомментированный
пример подключения через Groq (OpenAI-совместимый клиент). Когда решишь,
какой сервис использовать:

1. Зарегистрируйся и получи API-ключ.
2. Впиши его в `.env` (`AI_PROVIDER`, `AI_API_KEY`, `AI_MODEL`).
3. Раскомментируй и адаптируй код в `get_ai_response()`.
4. Добавь нужную библиотеку в `requirements.txt` (например `openai` для Groq/OpenRouter).
